# Code of Conduct

This project follows the Contributor Covenant Code of Conduct, version 2.1.

## Our standard

Contributors are expected to be respectful, constructive, and focused on the
technical substance of the project. Harassment, personal attacks, and repeated
disruptive behavior are not acceptable.

## Enforcement

Report conduct concerns to the maintainer listed in `package.json`. Maintainers
may remove comments, close issues, or block participants when needed to keep
the project usable for contributors.
